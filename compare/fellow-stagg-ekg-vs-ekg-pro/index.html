How to read this

Power, temperature, hold, and capacity as Fellow states them for the Stagg EKG card and the EKG Pro.

Each line below is copied from that model’s maker page. The Source link opens that page. A spec that only one card lists is left out of the table. Recall lines use the 2026-11-12 (UTC) catalogue check.

The catalogue card for the Stagg EKG records 1200 W, to-the-degree control, a hold that keeps the set temperature while you pour, and both 0.9 L and 1.5 L sizes on the Fellow page. The current Pro variant on that page lists 0.9 L, 1000–1200 W, and a temperature range of 104°F to 212°F.

Fellow’s model menu on the page now offers Pro and Pro Studio Edition. Pro Studio uses the same precision features with different materials. This comparison uses the Pro details, not a guess about a discontinued kettle.

The page the card cites now opens on the Pro

The Stagg EKG card points at Fellow’s electric pour-over kettle page and records two capacities, 0.9 L and 1.5 L, plus 1200 W. Opening that page now shows a model selector for Pro and Pro Studio Edition, and the Pro details block lists a single capacity of 30 oz, which is 0.9 L. The 1.5 L figure remains on the card as what was recorded from that URL. It is not the capacity in the Pro details block.

Pro power is printed as 110–120 V, 1000–1200 W, 50–60 Hz. The card’s power line is 1200 W. The top of the Pro range matches the card. The bottom of the range, 1000 W, is only on the Pro details. Temperature on the Pro is 104°F to 212°F. The card says to-the-degree control and does not print that range.

Hold, schedule, and the Studio edition

The card’s hold line says the kettle keeps the set temperature while you pour. The Pro page lets you set the hold to 15, 30, 45, or 60 minutes. Those are different sentences. The Pro page also names scheduling, a brew stopwatch, altitude, a chime, Fahrenheit or Celsius, and firmware updates through the EKG Updater app. Fellow says the app does not control the kettle remotely. Pro Studio Edition, on the same page, is described as the same precision performance with a glass top, metal accents, and different touch points.

Dimensions in the Pro details are 11.10 by 6.77 by 7.7 inches. Weight is 1,400 g, including the base. The warranty line on the comparison block is a 2-year standard warranty with an option to extend, and Fellow prints that line for the Pro. The EKG card does not carry a warranty spec, so the 2-year line stays off the shared table.

Pick the card you can still match to a box

Pick the Stagg EKG card if you are matching 1200 W and a listing that still offers the 0.9 L and 1.5 L sizes the card records. Confirm the model on the box. The Fellow page’s selector no longer shows a non-Pro EKG as a current variant.

Pick the EKG Pro if you are matching 0.9 L, the 1000–1200 W line, the 104°F to 212°F range, and a hold you set in 15-minute steps up to 60 minutes. Pro Studio is the materials variant on the same page, not a third capacity. There is no separate model page here for the Pro.

A gooseneck spout is the Pro’s pour-over description. A wide spout on Fellow’s comparison block belongs to the all-purpose column, not to the Pro details used here.
