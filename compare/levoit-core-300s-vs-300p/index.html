Levoit Core 300S-P vs Core 300-P: which one to buy

The 300S-P is 39 W and 7.48 lb, and the 300-P is 56 W and 7.9 lb, in the same cabinet.

Get the Core 300S-P if

  • You want the lower power draw, 39 W.
  • You want the lighter unit, at 7.48 lb.
  • You want a noise range of 22–54.5 dB.

How to read this

The 300S-P is 39 W and 7.48 lb, and the 300-P is 56 W and 7.9 lb, in the same cabinet.

Each line below is copied from that model’s maker page. The Source link opens that page. A spec that only one card lists is left out of the table. The recall line is the CPSC and Health Canada check dated 2026-11-14 (UTC).

The catalogue model is the Core 300S-P, not a separate Core 300S card. Levoit’s Core 300-P sales page is a different listing. The shared rows are power supply, rated power, noise, dimensions, and weight.

Both pages print a cabinet of 8.7 by 8.7 by 14.2 inches. The 300S-P manual says 39 W, 22–54.5 dB, and 7.48 lb. The 300-P sales page says 56 W, 24–54.5 dB, and 7.9 lb.

The names are easy to cross

Levoit sells a page titled Core 300-P. In that page’s specification block the model line reads Core 300. The same page’s included-items heading names the Core 300S-P. Read the title on the listing and the model on the box before you treat those three strings as one machine. This catalogue has a card for the Core 300S-P. It does not have a separate card for a Core 300S or for the Core 300-P.

The 300-P manual covers the Core 300 series and the Core 300-P series. Its CADR block lists smoke 143 CFM, dust 153 CFM, and pollen 167 CFM. The sales page prints a single CADR of 143 CFM. The table uses the sales-page figure. The manual’s three-number line is the other official sentence, and it is linked from the source list below.

Same cabinet, different watt and weight lines

Dimensions match: 8.7 × 8.7 × 14.2 in on the 300S-P manual and 8.7 x 8.7 x 14.2 in on the 300-P sales page. Power supply is AC 120 V, 60 Hz on both. Rated power is 39 W on the 300S-P manual and 56 W on the 300-P page. Weight is 7.48 lb against 7.9 lb. Noise is a range on both pages, 22–54.5 dB on the 300S-P manual and 24–54.5 dB on the 300-P page. A lower stated wattage and a lower stated weight are the 300S-P lines.

Room size and CADR are on the 300-P page and not on the 300S-P card, so they stay off the shared table. The 300-P page says 1066 ft2 at 1 air change per hour, or 222 ft2 at 4.8. Do not borrow the Core 600S-P CADR for either of these small cabinets. That figure lives on the 600S-P comparison.

Pick the card whose model string you can match

Pick the Core 300S-P if the box and the listing say Core 300S-P, and the figures you are matching are 39 W, 7.48 lb, and 22–54.5 dB in an 8.7 by 8.7 by 14.2 in cabinet. That is the model on the catalogue card.

Pick the Core 300-P sales page if the listing title is Core 300-P and the figures you are matching are 56 W, 7.9 lb, 24–54.5 dB, and the 1066 ft2 or 222 ft2 room lines. Then read the spec block’s model line, which prints Core 300, and the included-items heading, which names the 300S-P. If those strings do not match the carton, stop and use the string on the carton.

A CADR of 143 CFM on the sales page and a smoke CADR of 143 CFM in the manual are the same first number. Dust 153 and pollen 167 appear in the manual and not as separate lines on the sales page. The manual link is on the Manual CADR line under the table.
