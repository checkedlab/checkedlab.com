How to read this

Suction and robot dimensions as the Roborock and eufy pages state them for the Qrevo S and the X10 Pro Omni, with a dated recall line for each.

Each line below is copied from that model’s maker page. The Source link opens that page. A spec that only one card lists is left out of the table. Recall lines use the 2026-11-12 (UTC) catalogue check.

The Qrevo S page states 7,000 Pa and robot dimensions of 13.78 x 13.9 x 3.80 in. The X10 Pro Omni page states 8,000 Pa and robot dimensions of 327 mm x 353 mm x 113.5 mm.

A higher stated suction figure is the X10 Pro Omni line. The dimension rows use the units each maker page prints, inches on the Roborock page and millimetres on the eufy page.
